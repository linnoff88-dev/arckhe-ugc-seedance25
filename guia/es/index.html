Qué es

La receta del pack "Seedance 2.5 UGC Ads", en tu flujo

El pack (Zubair Trabzada · AI Workshop, 2026) enseña una receta de 3 pasos y 9 formatos para anuncios que parecen grabados por una persona real con el celular. Este proyecto convierte la receta en dos herramientas: una skill para Claude Code y un generador de briefs web.

🎬 One-take de 30 s

Seedance 2.5 genera todo el anuncio de una vez: mismo rostro, misma voz, mismo producto, sin cortes. 9:16, 1080p, audio nativo con lip-sync.

🧩 9 formatos listos

Reseña, confesión en la mesa, rutina nocturna, unboxing, try-on, POV solo con las manos, prueba de sabor y dos "trae tu producto" (foto o captura de la tienda).

🛡️ Reglas para evitar el AI-slop

Producto en cuadro durante los primeros 3 segundos, bloque de realismo, cada frase entre comillas con marca de tiempo, sonidos prohibidos, QA con fotogramas congelados.

Cómo funciona

Tres generaciones, siempre en el mismo orden

Los prompts están en inglés (el modelo los interpreta mejor); solo las frases entre comillas van en el idioma elegido, PT-BR de forma predeterminada. Cinco beats con marcas de tiempo guían la actuación: 70–80 palabras habladas caben en 30 s.

Brief del producto→ STEP 1 · foto del producto→ STEP 2 · retrato del creator→ STEP 3 · video one-take→ QA con fotogramas
1

Producto

Foto limpia de e-commerce, etiqueta corta (marca + dos líneas). Se convierte en la identidad del producto en todos los anuncios.

2

Creator

Retrato "cámara frontal de iPhone, sin retoques", en el mismo espacio, con la ropa y la iluminación exactas del video. El mismo rostro sirve para una serie.

3

Video

Shot list de 5 beats: hook (0–4 s), qué es (4–11 s), demo (11–18 s), resultado (18–25 s), cierre (25–30 s). Bloque de realismo y bloque de audio.

Requisitos previos

Qué debe estar en línea

El generador en modo Template funciona en cualquier navegador, sin servidor. La skill y el modo IA usan lo que ya tienes en Claude Code.

Claude Code (skill y modo IA)

La skill se ejecuta dentro de Claude Code. El modo IA de la app usa OAuth de Claude Code de forma predeterminada, sin clave de API.

# en la máquina donde se ejecutará la app
claude login

Node 20+ (app local)

Solo para el modo IA. El modo Template es estático.

cd app && npm install
npm run dev   # http://localhost:3040

Una plataforma con Seedance 2.5

Magnific (MCP, predeterminado), Higgsfield o fal.ai. La app cambia los encabezados de los parámetros para cada uno. Generar consume créditos; la skill simula el costo antes.

# herramientas de QA (opcional)
ffmpeg -version
Guía de uso · paso a paso

Del producto al brief listo

Dos caminos para obtener el mismo resultado: el generador web (sin instalar nada) o la skill en Claude Code (que también puede ejecutarse en Magnific).

1

Abre el generador y completa el brief

Marca, producto en una línea, quién compra, origen del producto (desde cero, foto o captura de la tienda), formato (01–09), creator, idioma de las frases y plataforma de destino.

https://inematds.github.io/ugc-seedance25/app/public/  # modo Template, sin servidor
# o local, con modo IA mediante OAuth de Claude Code:
cd app && npm install && npm run dev
2

Escribe (o genera) los 5 diálogos

Modo Template: escribes las frases en los 5 campos y el contador avisa si sales del rango de 70–80 palabras. Modo IA: Claude escribe el producto, el creator, las acciones de los beats, las 5 frases en el idioma elegido y 2–3 hooks alternativos.

# ejemplo de diálogo para el hook (formato 07, prueba de sabor)
"Todo energético diz que não sabe a remédio. Toda vez é mentira."
3

Copia los 3 prompts con los parámetros de la plataforma

Cada STEP tiene un botón para copiar y el encabezado con los parámetros del destino elegido. "Copiar brief completo" o "Descargar .md" incluye todo de una vez, con la lista de verificación de QA.

# PASO 3 en Magnific
video_generate · slug bytedance-seedance-pro-2.5 · 9:16 · 1080p · duration 30
references[]: {type:'product', STEP 1} + {type:'character', STEP 2} · sem keyframes
4

O usa la skill en Claude Code

La skill pregunta lo que falte en el brief, elige el formato según el producto, escribe los 3 prompts y guarda un brief.md. Solo se ejecuta en Magnific si lo pides, y siempre con una simulación de costos antes.

# instalar (symlink al repo clonado)
ln -s ~/projetos/ugc-seedance25/skill/ugc-seedance25 ~/.claude/skills/ugc-seedance25
# usar
/ugc-seedance25 anúncio ugc do meu sérum, tenho a foto em ~/fotos/serum.jpg
# salida: ~/projetos/output/ugc-seedance25/<slug>/brief.md
5

Genera con control de costos: borrador en 720p, versión final en 1080p

En Magnific, la skill ejecuta simulate_cost y muestra el número antes de generar. Después: foto del producto, retrato del creator, borrador en 720p, aprobación, versión final en 1080p. ¿La voz en PT-BR quedó mal? Genérala en inemavox y pásala como referencia de audio.

# orden fija
simulate_cost → STEP 1 → STEP 2 → vídeo 720p → QA → vídeo 1080p
6

QA con fotogramas congelados, no con sensaciones

Hoja de contactos 3×3 y revisión del espejo. Un solo producto, máximo dos manos, etiqueta legible y en el sentido correcto, rostro igual al del retrato, sin subtítulos incrustados, producto visible antes de 3 s.

ffmpeg -y -i ad.mp4 -vf "fps=0.3,scale=360:-1,tile=3x3" contact.png
ffmpeg -y -i ad.mp4 -vf hflip -c:a copy ad-fixed.mp4   # si la etiqueta salió invertida
